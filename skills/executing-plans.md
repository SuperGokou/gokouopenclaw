# Executing Plans — 按计划执行

## 概述

加载计划，批判性地审查，执行所有任务，完成后报告。

**开始时宣布：** "我正在使用 executing-plans 技能来实现这个计划。"

## 流程

### 第一步：加载并审查计划

1. 阅读计划文件
2. 批判性地审查——找出任何问题或疑虑
3. 如果有疑虑：在开始之前与用户讨论
4. 如果没有疑虑：创建任务列表并继续

### 第二步：执行任务

对每个任务：
1. 标记为进行中
2. 严格遵循每个步骤（计划有分解好的小步骤）
3. 按规定运行验证
4. 标记为已完成

### 第三步：完成开发

所有任务完成并验证后：
- 使用 `verification-before-completion` 技能进行最终验证
- 报告完成状态，附带证据

## 何时停止并寻求帮助

**立即停止执行：**
- 遇到阻碍（缺少依赖、测试失败、指令不清楚）
- 计划有关键缺口阻止开始
- 你不理解某条指令
- 验证反复失败

**寻求澄清，而不是猜测。**

## 原则

- 先批判性地审查计划
- 严格遵循计划步骤
- 不跳过验证
- 遇到阻碍时停止，不要猜测
- 未经明确用户同意，永远不要在主分支上开始实现
